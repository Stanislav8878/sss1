# Домашнее задание: Классы Product и Category

## Описание
Реализованы классы для управления товарами и категориями интернет-магазина:
- **Product**: Хранит данные о товаре (название, описание, цена, количество).
- **Category**: Содержит список товаров и автоматически подсчитывает общее количество категорий и товаров.

## Функционал
1. Создание товаров и категорий.
2. Автоматический подсчет статистики (количество товаров/категорий).
3. Загрузка данных из JSON-файла.

# Магазин электроники: Управление категориями и товарами

Проект представляет собой систему управления товарами и категориями для интернет-магазина электроники. Реализованы классы `Product` и `Category` с защитой данных через приватные атрибуты, геттеры/сеттеры, а также методы для добавления товаров и обработки дубликатов.


## Функциональность**

### 1. Класс `Product`**
- **Приватный атрибут цены** (`__price`), защищенный от некорректного изменения.
- **Геттер и сеттер для цены**:
  - Проверка на положительное значение.
  - Подтверждение при снижении цены (доп. задание).
- **Класс-метод `new_product`**:
  - Создает товар из словаря.
  - Обрабатывает дубликаты: объединяет количество и выбирает максимальную цену.
**Магические методы**:
  - `__str__`: строковое представление в формате "Название, X руб. Остаток: X шт."
  - `__add__`: сложение товаров по формуле (цена × количество) + (цена × количество)
### **2. Класс `Category`**
- **Приватный список товаров** (`__products`), доступный только через методы.
- **Метод `add_product`**:
  - Добавляет товар в категорию.
  - Увеличивает счетчик товаров (`product_count`).
- **Геттер `products`**:
  - Возвращает строку с товарами в формате:
    `"Название, X руб. Остаток: Y шт."`.
**Магические методы**:
  - `__str__`: строковое представление в формате "Название категории, количество продуктов: X шт."
  - `__iter__`: итерация по товарам категории
  ### 3. Класс CategoryIterator
- Реализует паттерн Итератор для перебора товаров категории
- Используется автоматически при итерации по объекту Category

### **3. Загрузка данных из JSON**
- Функция `load_categories_from_json` загружает категории и товары из файла `products.json`.
