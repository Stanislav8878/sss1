# Домашнее задание: Классы Product и Category

## Описание
Реализованы классы для управления товарами и категориями интернет-магазина:
- **Product**: Хранит данные о товаре (название, описание, цена, количество).
- **Category**: Содержит список товаров и автоматически подсчитывает общее количество категорий и товаров.

## Функционал
1. Создание товаров и категорий.
2. Автоматический подсчет статистики (количество товаров/категорий).
3. Загрузка данных из JSON-файла.
